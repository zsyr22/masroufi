# Masroufi Fuel v1.1

## Included
- Search by station, fuel type, account, and odometer.
- Date filters: all dates, this month, last month, and this year.
- Sorting: newest, oldest, highest cost, and lowest cost.
- Total fill-up count.
- Last fill-up summary card.
- Station identity badges for ADNOC, ENOC/EPCO, and Emarat, with a fallback badge for other stations.
- Color-coded fuel-type badges.
- Improved responsive fuel cards and no-results state.

## Database
No Supabase migration is required for this release.

## Run
```bash
npm install
npm run dev
```

## Validate
```bash
npm run lint
npm run build
```
