# Masroufi People UI update

## Included
- Edit person details (name, phone, notes)
- Delete people with no ledger history
- Archive people that already have financial history
- Premium People list UI matching the Dashboard visual language
- Premium Person details UI with glow, gradients, hierarchy, and responsive layout

## Database
No Supabase migration is required. Existing RLS and delete-protection rules are used.

## Run
```powershell
npm run lint
npm run build
npm run dev
```
