# Masroufi — Purchase Store Analytics v1

This update adds store-level spending analytics directly to the Purchases page.

## Included
- Period filters: This month, Last month, This year, All time.
- Store spending cards sorted by spend.
- Click a store to filter purchase history to that store.
- All stores card to reset the filter.
- Top store is now based on amount spent, not visit count.
- AED totals are kept separate from USD totals.
- Existing purchase history and receipt cards are preserved.

## Database
No Supabase migration is required. This feature uses existing purchase/store data.
